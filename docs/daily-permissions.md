# 日报权限

常规日报公开采集、补证和工作区内生成按用户已授权流程执行。Codex的宿主沙箱与审批模式由应用控制；用户可在可用时选择自动审批。脚本不能授予自身权限，也不保证零弹窗。

使用 `tools/daily-network.ps1` 的固定入口。联网被拒绝后保留断点并如实报告，不更换工具绕过。代理优先显式参数、DSH_HTTP_PROXY、HTTPS_PROXY、HTTP_PROXY、ALL_PROXY；未配置则直连。凭据仅在本机环境或已登录的凭据管理器中读取，不应粘贴到聊天或写入发布包。

页面预览受限时，双击 `打开工具库.cmd`。该入口需要PowerShell 7和Python 3.9以上，服务只监听127.0.0.1。
