# 项目改名：开源案卷 · RepoDossier

v1.3.0 起采用新名字。项目已经包含开源发现、证据核验、变化跟踪、中文日报和本地工具库，原名 DSH-Skill-Collection 容易被理解成只供 DSH 使用的技能列表。

仓库新地址为 https://github.com/Kalekaer/RepoDossier 。GitHub支持旧仓库网页与Git地址跳转；本项目没有 GitHub Pages，也不作为可复用GitHub Action发布。后续不要重新占用旧仓库名，以免覆盖跳转。

技能目录和口令 `github-daily-picks`、`tool-stack` 保留，原始文件名和数据契约不批量改名。旧发布版本与附件保留，新附件使用 `repodossier-v<版本>.zip`。

本机目录可以自行选择，无需移动已有个人工作区。已有Git检出可将origin更新到新仓库地址；不要为改名重新导入或覆盖个人数据。
