把普通 JavaScript 程序编译成神经网络，这件事听起来像论文标题，但它已经在 24 小时内吃掉 1,201 颗星。handwired 的定位是"研究型工具"——给那些愿意在编译层动手的人，而不是给应用开发者。

它不需要训练：权重由程序结构直接推导，因此没有反向传播、没有数据集、没有调参窗口。它可微：你能对编译出来的网络求梯度。它能上 WebGPU：推理跑在浏览器里。

⚠ 研究型工具不是生产线工具：没有文档站、没有版本承诺、API 会变。适合"先看它怎么想"，不适合"明天上线"。

同期的 BRUTAL 走的是相反路线：把游戏引擎的底座做成 C# 框架，互操作层直连原生 API，附带 Vulkan / GLFW / Dear ImGui / FMOD / RakNet / Jolt / Box2D 绑定。RimWorld 用它做了 Waylith 引擎，自测是 Unity 版的 2–4 倍性能；Kitten Space Agency 直接跑在上面。

代价很清楚：它不是 Unity/Godot——没有编辑器、没有场景图、没有渲染器，README 自己写"某些方面比 Unity 难得多"。许可是"MIT + 署名要求"：游戏 credits 要写明、开场显示 BRUTAL logo、随包发 NOTICE.txt。

上手：.NET 10 SDK → dotnet add package Ahwoo.Brutal.Glfw → dotnet run（README 给了最小窗口代码）。
